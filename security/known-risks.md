# 已知风险

## 当前已知限制

1. 合约目前只支持原生 ETH 众筹，不支持 ERC20
2. 没有暂停机制，线上异常时不能通过管理员开关止损
3. 没有升级机制，合约一旦部署，逻辑修复需要新部署
4. indexer 基于轮询与事件回放，数据库存在短暂同步延迟
5. 前端直接依赖用户钱包与 RPC，可用性受外部钱包和节点影响

## 运维风险

1. `contractAddress` 配错会导致 API 与 indexer 指向错误合约
2. `deploymentStartBlock` 配错会漏事件或重复追块
3. 将示例 RPC 占位符直接用于生产会导致启动失败
4. 将真实链配置文件提交进仓库会泄露基础设施信息

## 后续建议

1. 补充更多后端测试和链上回归测试
2. 在上线前增加一次内部安全评审
3. 为 indexer 增加同步延迟告警
