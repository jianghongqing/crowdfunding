# 威胁模型

## 资产

- 用户 ETH
- 合约状态
- 数据库索引结果
- 链配置文件
- 部署环境中的数据库与 RPC 凭据

## 信任边界

- 链上合约：业务真相源
- API：查询层，不应拥有资金操作权限
- indexer：同步层，不应发交易
- 前端：交互入口，不应持有私钥

## 主要威胁

1. 合约业务逻辑漏洞
2. 错误配置导致后端读错链或错合约
3. RPC 不稳定导致索引中断
4. 索引延迟导致前端读到旧状态
5. 本地工具把敏感配置或大文件误提交

## 对应控制点

1. 通过 Foundry 测试约束合约逻辑
2. 通过 `backend/config/README.md` 统一配置入口
3. 通过 `monitoring/README.md` 定义观测指标
4. 通过 `.claude/` 约束协作提示和上下文读取范围
