# 代码评审安全清单

评审涉及合约、索引器、API 或前端改动时，建议重点看这些问题：

## 合约

- [ ] 是否引入了新的资金流路径
- [ ] 是否可能出现重入
- [ ] 是否可能重复提现或重复退款
- [ ] 是否修改了事件定义，且同步更新了链下依赖
- [ ] 是否改变了状态判断逻辑

## Indexer / API

- [ ] 是否破坏了 API 与 indexer 的兼容性
- [ ] 是否修改了数据库字段但没有 migration
- [ ] 是否存在数据库快照与链上状态不一致的新风险
- [ ] 是否把链上兜底逻辑删掉了

## 配置 / 部署

- [ ] 是否引入了写死的环境值
- [ ] 是否把示例配置误当成生产配置
- [ ] 是否扩大了容器暴露面
- [ ] 是否有新的敏感变量需要文档化

## 前端

- [ ] 是否把交易职责从钱包错误地挪到了后端
- [ ] 是否暴露了不该暴露的内部地址或敏感信息
- [ ] 是否把 API 路径、网络 ID、合约地址写死
