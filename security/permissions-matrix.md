# 权限矩阵

## 当前合约

`src/CrowdFund.sol` 当前没有传统管理员角色，也没有升级入口。

按现有代码逻辑，关键权限如下：

- `createCampaign`
  - 任何地址都可调用
- `fund`
  - 任何地址都可调用
- `withdraw`
  - 仅活动创建者可调用
- `refund`
  - 仅有贡献记录的地址可调用自己的退款

## 后端

- `api`
  - 仅读取链上与数据库数据
  - 不持有用户私钥
- `indexer`
  - 仅读取链上事件并写库
  - 不发交易

## 当前结论

- 没有中心化管理员提走用户资金的入口
- 风险重点在合约逻辑正确性、配置正确性和索引一致性
- 如果未来加入 `owner`、暂停、升级等能力，必须先更新本文件
