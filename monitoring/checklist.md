# 运行巡检清单

建议上线后按固定频率巡检：

## 每日

- [ ] `GET /healthz` 正常
- [ ] indexer 最近 24 小时无长时间停滞
- [ ] MySQL 可连接
- [ ] 没有明显 RPC 超时或失败激增

## 每次发版后

- [ ] API 启动成功
- [ ] Indexer 启动成功
- [ ] checkpoint 继续推进
- [ ] 前端能正常读取活动列表
- [ ] 前端能正常发起一笔测试交易

## 出现异常时

- [ ] 检查 RPC 可达性
- [ ] 检查链配置是否仍指向正确合约
- [ ] 检查数据库连接与表结构
- [ ] 检查最近是否有未同步记录的部署变更
